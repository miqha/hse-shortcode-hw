# hse-shortcode-hw
Репозиторий с домашними заданиями по короткому коду, выданными на курсе по высшей математике и математической статистике в первом семестре магистрской программы «Машинное обучение и анализ данных» НИУ ВШЭ СПб.

## Задание 1

Необходимо составить максимально лаконичный код, который осуществлял бы построение выборочной функции распределения для заданной выборки и производил бы оценку выборочной квантили для заданной вероятности. Чем короче код, тем лучше.

## Задание 2

Необходимо составить максимально лаконичный код, который осуществлял бы построение ядерной оценки плотности (KDE) для заданной выборки. Чем короче код, тем лучше.

## Задание 3

Прошу Вас составить максимально лаконичный код, который осуществлял бы оценку интересующего параметра по заданной выборки для плотности распределения, заданной отдельной функцией. Чем короче код, тем лучше.

Спецификация программы предполагается следующей: есть процедура, реализующая метод максимального правдоподобия в численной форме (оптимизация), условно назовем ее p_est = MLE(@pdf, x, p0). Ей на вход передается указатель или ссылка @pdf на функцию pdf, которая реализует вычисление значения плотности распределения: y = pdf(t, p), где t - аргумент плотности, p - вектор параметров, от которых зависит плотность и для которых производится вычисление значения оценки методом максимального правдоподобия, y - возвращаемое значение плотности. Вектор p0 - это начальные приближения оценок параметров (например, все нули - это значения, с которых начинается поиск оценок при численной оптимизации). Вектор p_est - это возвращенные значения оценок.

## Задание 4

Прошу Вас составить максимально лаконичный код, который рассчитывал бы по заданной выборке следующие точечные оценки: 
1) математического ожидания и медианы, 
2) дисперсии и среднеквадратического отклонения (два варианта - смещенную и несмещенную оценку при использовании в качестве оценки математического ожидания выборочного среднего), 
3) несмещенную оценку коэффициентов асимметрии и эксцесса
