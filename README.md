# hse-shortcode-hw
Репозиторий с домашними заданиями по короткому коду, выданными на курсе по высшей математике и математической статистике в первом семестре магистрской программы «Машинное обучение и анализ данных» НИУ ВШЭ СПб.

## Задание 1

Необходимо составить максимально лаконичный код, который осуществлял бы построение выборочной функции распределения для заданной выборки и производил бы оценку выборочной квантили для заданной вероятности. Чем короче код, тем лучше.
